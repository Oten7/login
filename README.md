# Login Hexa

Protótipo visual de uma página de login em **HTML e CSS**.

## Interface

- Campos de e-mail e senha.
- Opção visual de lembrar senha.
- Links de recuperação de senha e cadastro.
- Ícones do Boxicons.

**Estado atual:** interface de estudo, sem servidor, autenticação ou cadastro de contas. Os links de recuperação e cadastro são marcadores.

## Visualizar

Abra `index.html` no navegador. É necessária internet para carregar os ícones externos.
